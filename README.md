# Mobility Price Watch

Compares like-for-like used, ex-demo and refurbished mobility products across retailers.

## Matching rules

The matcher is deliberately conservative. It does not compare products merely because they share a brand, category, battery type, colour, or generic words. A listing must share a distinctive model identifier before it can be automatically compared.

Examples:
- Abilize Aeron Li ≠ Abilize Ranger Li 3
- CareCo Stratus = Stratus when the model identity is otherwise consistent

Products that cannot be confidently matched should remain unmatched rather than producing a misleading price comparison.
